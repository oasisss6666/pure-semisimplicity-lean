# Lean 4 formalization: a counterexample to the pure semisimplicity conjecture

This project formalizes the manuscript *A counterexample to the pure semisimplicity conjecture*
(`manuscript/source.tex`, SHA-256 `5620351c8e5eb777f2751dc7e9621b7ef90fd2951457f16f3e860cc7369d5f6b`)
in Lean 4 with Mathlib. The two headline results are in `QuantumFlags/MainTheorem.lean`.

## Headline statements

```lean
theorem pure_semisimplicity_conjecture_fails :
    ∃ (R : Type) (_ : Ring R), IsRightPureSemisimple.{0,w} R ∧ ¬ IsFiniteRepresentationType.{0,w} R
```

```lean
theorem main_theorem :
    -- `T` is the increasing union of the `T_n`
    (Monotone oreLayer ∧ ∀ a : OreUnion, ∃ n, a ∈ oreLayer n) ∧
    -- the `ℚ`-subalgebra of `T_n = OreLevel n = QuantumLevel (1/2) _ n` generated by
    -- `t_1^{±1}, …, t_n^{±1}` is the quantum Laurent algebra `𝒜_n` with `q = 1/2`: it has the
    -- monomial basis `M_a = t_1^{a_1} ⋯ t_n^{a_n}` with `M_a M_b = (1/2)^{∑ a_{i+1} b_i} M_{a+b}`;
    -- and `T_n` is its division ring of fractions
    (∀ n,
      (∃ b : Module.Basis (Fin n → ℤ) ℚ (quantumLaurentSubalgebra (1/2) quantumHalf_ne_zero n),
        (∀ a, (b a : QuantumLevel (1/2) quantumHalf_ne_zero n) =
          (List.ofFn fun i => quantumGenerators (1/2) quantumHalf_ne_zero n i ^ a i).prod) ∧
        ∀ a c, b a * b c = ((1/2 : ℚ) ^ quantumExponent n a c) • b (a + c)) ∧
      ∃ e : OreLocalization (quantumLaurentSubalgebra (1/2) quantumHalf_ne_zero n)⁰
        (quantumLaurentSubalgebra (1/2) quantumHalf_ne_zero n) ≃+* QuantumLevel (1/2) quantumHalf_ne_zero n,
      ∀ a, e (OreLocalization.numeratorRingHom a) = a) ∧
    -- `t = t_1`
    actualFlagSystem.t = oreEmbed 1 (quantumGenerators (1/2) quantumHalf_ne_zero 1 0) ∧
    -- `H_r = κ_r(T)` with `κ_r` given on `T_n` by conjugation with `Γ_{n,r}`, and `H_0 = T`
    (∀ r, actualFlagSystem.H r = (kappa actualQuantumChain r).fieldRange) ∧
    (∀ r n (a : OreUnion), a ∈ oreLayer n →
      kappa actualQuantumChain r a = gamma oreVariable r n * a * (gamma oreVariable r n)⁻¹) ∧
    actualFlagSystem.H 0 = ⊤ ∧
    -- condition (B)
    (∀ r, 1 ≤ r → Function.Bijective (wideEval (actualFlagSystem.H r).subtype
      (fun i : Fin (r+1) => actualFlagSystem.t ^ i.val))) ∧
    -- condition (F)
    (∀ p, 1 ≤ p →
      Function.Injective (leftEval (actualFlagSystem.H p).subtype actualFlagSystem.t) ∧
      Function.Injective (rightEval (actualFlagSystem.H (p+1)).subtype actualFlagSystem.t) ∧
      Set.range (leftEval (actualFlagSystem.H p).subtype actualFlagSystem.t) =
        Set.range (rightEval (actualFlagSystem.H (p+1)).subtype actualFlagSystem.t)) ∧
    -- right dimension sequence `(1,2,2,2,...)`
    (∀ n, FiniteDimensional
        (iteratedRightDual (ambientBimodule (actualFlagSystem.H 1)) n).RightRingᵐᵒᵖ
        (iteratedRightDual (ambientBimodule (actualFlagSystem.H 1)) n).Space ∧
      Module.finrank (iteratedRightDual (ambientBimodule (actualFlagSystem.H 1)) n).RightRingᵐᵒᵖ
        (iteratedRightDual (ambientBimodule (actualFlagSystem.H 1)) n).Space =
          if n = 0 then 1 else 2) ∧
    -- `dim ₕT = ∞`
    ¬ FiniteDimensional (actualFlagSystem.H 1) OreUnion ∧
    -- `R` is right pure semisimple, not left pure semisimple, not of finite representation type
    IsRightPureSemisimple.{0,w} ActualTriangularRing ∧
    ¬ IsLeftPureSemisimple.{0,w} ActualTriangularRing ∧
    ¬ IsFiniteRepresentationType.{0,w} ActualTriangularRing
```

Here `OreUnion` is the union `T` of the division rings `T_n = OreLevel n`, `actualFlagSystem.t` is
`t = t_1`, `actualFlagSystem.H r` is `H_r = κ_r(T)`, and `ActualTriangularRing` is the matrix ring
`R = (H T; 0 T)` with `H = H_1`.

## Machine-check results

`python3 verify.py` builds the whole project and then runs `#print axioms` on every theorem
declared in the project sources (832 theorem declarations, including auxiliary lemmas). The
recorded result is

```
PASS: 832 theorems; axiom set ['Classical.choice', 'Quot.sound', 'propext']; thm:main audited.
```

The only axioms used are the standard `propext`, `Classical.choice` and `Quot.sound`. The
verifier also scans the sources and rejects `sorry`, `admit`, `axiom`, `unsafe` and
`native_decide`. Its full output is in `verification.log`; the regenerated audit file is
`AxiomAudit.lean`, and `verification_status.json` records source hashes and the result.

These checks certify the Lean statements as written. Whether the definitions and statements
faithfully express the manuscript is a matter for mathematical review; see the notes below.

## Reproducing the checks

Requirements: Lean via `elan` (the file `lean-toolchain` selects `leanprover/lean4:v4.34.0`),
Python 3 and Git. Mathlib is pinned by `lake-manifest.json`
(revision `5ed2965256430c3649e86755f9576b54eca72435`). From this directory:

```sh
lake exe cache get
lake build
python3 verify.py
```

The first command downloads the dependencies and the Mathlib build cache, so it needs an internet
connection. A full build of the project itself takes roughly 20 minutes on a laptop. On success the
last line printed by `verify.py` begins `PASS: 832 theorems`. On another computer the informational
field `original_source_still_matches_snapshot` may be `false`, because it refers to the absolute
manuscript path on the original machine; the verifier separately checks `manuscript/source.tex`
against its recorded hash.

## Formalization choices to review

- **Right modules.** A right module over a ring `Λ` is a module over the opposite ring `Λᵐᵒᵖ`.
  The ring `ActualTriangularRing` itself is the ordinary upper-triangular matrix subring.
- **Pure semisimplicity and representation type.** `IsRightPureSemisimple Λ` says that every
  right `Λ`-module is linearly isomorphic to a direct sum of finitely generated right modules.
  `IsFiniteRepresentationType Λ` says that there are only finitely many isomorphism classes of
  finitely generated indecomposable right modules and only finitely many of left modules. These
  predicates quantify over modules in a universe `w`; the theorems hold for every `w`.
- **Left pure semisimplicity and the theorem of Chase.** The manuscript deduces that `R` is not
  left pure semisimple from the failure of the descending chain condition on left ideals together
  with the theorem of Chase (source lines 75 and 421). **The general theorem of Chase is not
  formalized and is not used.** Instead, failure of left pure semisimplicity is proved directly
  (`QuantumFlags/LeftPureSemisimplicityFailure.lean`): `T` is countable, while
  `Hom_H(T, H)` is uncountable because `T` contains an infinite left `H`-independent family, and
  the left `R`-module `(H, Hom_H(T, H), ev)` cannot be a direct sum of finitely generated modules.
- **Quantum Laurent algebras.** `lem:qtorus` is proved for every nonzero rational `q`
  (`QuantumFlags/QuantumTower.lean` and `QuantumFlags/QuantumLaurent*.lean`). The quantum Laurent
  algebra `𝒜_n` is formalized as the `ℚ`-subalgebra of `T_n` generated by `t_1^{±1}, …, t_n^{±1}`,
  together with the theorem that it has the monomial basis `M_a = t_1^{a_1} ⋯ t_n^{a_n}` with
  multiplication `M_a M_b = q^{∑ a_{i+1} b_i} M_{a+b}`, is a two-sided Ore domain, and has `T_n` as its
  division ring of fractions. The tower of the counterexample is definitionally the case `q = 1/2`.
- **Decomposition lemma.** The final step of `lem:decomp` uses a coordinate of maximal type
  instead of nilpotency on a finite coordinate summand; the argument is equivalent.
- **Generality.** Sections 2 and 3 of the manuscript are proved for every division bimodule with
  right dimension sequence `(1,2,2,...)`, not only for bimodules of the form `ₕT_T`.

## Layout

- `QuantumFlags.lean`: root module importing all certified sources.
- `QuantumFlags/`: the proofs (one file per topic).
- `QuantumFlags/MainTheorem.lean`: `main_theorem` and `pure_semisimplicity_conjecture_fails`.
- `verify.py`: build, source scan and axiom audit.
- `manuscript/source.tex`: the manuscript snapshot; `manuscript/source_metadata.json`: its hash
  and labelled declarations; `manuscript/coverage.json`: Lean theorems for each label.
